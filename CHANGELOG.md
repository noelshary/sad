# Changelog

## 1.0.0
- First release: color menu with 40 colors + HEX input
- Strength slider (from see-through to fully solid)
- Animations: Static, Pulse, Rainbow, Shimmer, Strobe
- Hit particles and sounds
- Keybind (default `H`) and Mod Menu support

## 1.1.0
- New color picker (saturation/brightness field + hue bar)
- Test bot in the menu with a "Hit" button
- New animations: Fade out, Heartbeat, Fire; speed slider
